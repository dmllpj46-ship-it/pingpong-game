# PingPong 3D — 第一视角乒乓球（人 vs CPU）

一个跑在浏览器里的 3D 乒乓球游戏：**你就站在球台这端**，用鼠标挥拍，和一个会预判落点的 CPU 打 11 分制。纯前端，无后端、无账号、无安装、可离线运行。

背景是**会闪烁的星空**：渐变夜空穹顶 + 银河带 + 不同颜色/亮度的星点。观众席围着球场：三级环形看台、卡通观众、场边鲜花，全部用实例化网格绘制，不影响帧率。对面站着一个会跟着球左右移动的**卡通机器人对手**（发光眼睛、天线、挥拍手臂）。

> **当前状态：v1 可玩。** 已实现第一视角、自研物理、CPU 预判对手、完整计分、三档难度、合成音效与落点提示。

## 快速开始

**无需安装依赖、无需构建。** 任意静态服务器即可：

```bash
# 任选其一，在项目根目录执行
python -m http.server 8080
npx serve .
```

打开 <http://localhost:8080>。three.js 已放在 `vendor/`，**完全离线可用**。

> ⚠️ 不能直接双击 `index.html`（`file://` 会被 ES module 的 CORS 规则拦住）。
> 浏览器要求：支持 WebGL2 + import map（Chrome / Edge / Safari 16.4+ / Firefox 108+）。
> v1 不支持移动端触屏。

## 操作

| 输入 | 作用 |
|---|---|
| **鼠标左右** | **唯一需要移动的方向**：拍面左右对准来球。高度自动跟球、前后位置固定 |
| **`A` / `D`** | 横向精修（±0.25 m） |
| **单击左键** | 发球；回合中单击 = **挥拍接球**（开启 3.2 秒锁定窗口，提前很久点也有效） |
| **`Esc`** | 暂停 / 继续 |
| **`R`** | 重开一局 |

### 怎么打

1. 看到球往你这边来，**随便什么时候点一下左键**就行。窗口有 3.2 秒，点早了也不会失效（覆盖一整个来回）。球来而你还没点时，屏幕中间会提示「单击接球」。
2. 点完之后拍子会**自动横向咬住球的落点**、自动对齐高度，球到位就打出去；不用精确对准，也不用掐时机。
3. 鼠标左右仍然可以微调回球方向：拍面偏左，球会打去对方右边（对角）。
4. 左下角的「挥拍」条显示锁定窗口剩余时间。力度固定，不用蓄力。

## 规则（简化版）

- 11 分制，**净胜 2 分**获胜；每 2 分换发球，10:10 后每 1 分换发球。
- 失分情形：球在本方台面弹两次未回、回球出台/触网、发球未先落己方台面或两次落己方台面。
- v1 不判「未弹起截击」：球在你还没法回击时会直接穿过拍面，不会误扣分。
- 不做抛球高度、擦网重发、双打等 ITTF 细则。

开局菜单选择，三档参数集中在 `src/config.js` 的 `ai.levels`：

| 档位 | 反应延迟 | 移动速度 | 瞄准误差 | 漏球率 |
|---|---|---|---|---|
| 简单 | 320 ms | 2.2 m/s | ±0.18 m | 6% |
| 普通 | 220 ms | 3.2 m/s | ±0.09 m | 2% |
| 困难 | 140 ms | 4.2 m/s | ±0.035 m | 0%（打两大角+追身） |

## 调参 & 调试

所有数字都在 `src/config.js`：物理系数、拍面范围和挥拍窗口、击球飞行时间、AI 三档、发球搜索范围。

- 打开 `CONFIG.debug = true` → 显示坐标轴、判定球线框、实时状态面板（相位/落点计数/球速/挥拍窗口）。
- 浏览器控制台里有 `window.__pingpong`（暴露 `rules` / `ball` / `player` / `cpu` / `world` / `restart()`），方便自动化验证。
- 想换 CDN 版 three.js：改 `index.html` 里的 import map 一行即可，源码不用动。

## 已验证

- Chrome 无控制台报错，1080p 稳定 **60 fps**（含看台 + 1321 个观众/花朵实例）。
- 单击发球 + 单击挥拍：模拟玩家 9 秒内点 7 次，完成 **6 次回击 + 6 次 CPU 回击**，连续多拍无断；不点鼠标则球穿过拍面，不会自动接。
- **点早了也能接**：球刚被 CPU 打出时就单击（比球到位早约 0.85 秒），拍子自动锁定并完成回击；15 秒 10 次点击完成 8 次回击。
- 只动鼠标 X（完全不管高度和前后）的模拟玩家：9 秒内 **5 次玩家回击 + 4 次 CPU 回击**，连续多拍无断。
- 发球链路：己方落点 → 过网 → 对方落点 → CPU 回击 → 玩家回击（连续多拍实测）。
- 计分、每 2 分换发、10:10 每分换发、11 分净胜 2 分、结算与 `R` 重开均通过。
- 玩家发球后不接球、CPU 连续得分并自动换发，全流程无异常。
